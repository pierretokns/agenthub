## Decision Logic (Agent Brain)

When autonomous agent runs:

```
1. Load all results from results.jsonl
2. Filter to only those with contamination.passed=true
3. Get latest score & compute gradient (last 5 runs)
4. Decide next dataset:
   - score < 50: BRIGHT
   - score < 60: FollowIR
   - score < 70: MIRACL-en
   - score >= 70 & gradient < 0.1: MIRACL-{lang} (rotate through languages)
   - score >= 70 & gradient >= 0.1: Continue current
5. Set env vars for selected dataset
6. Launch: prime rl run configs/bright_baseline.toml
7. Monitor until COMPLETED
8. Verify: contamination.passed=true
9. Update leaderboard.tsv
10. Commit results to git
11. Sleep 30s, repeat
```

## Key Metrics & Thresholds

| Metric | Threshold | Action |
|--------|-----------|--------|
| Contamination | < 1% overlap | REQUIRED to pass |
| Primary Score | >= 50 | Baseline (BRIGHT) |
| | >= 60 | Above baseline (FollowIR) |
| | >= 70 | Good signal (MIRACL) |
| | >= 75 | SOTA territory |
| Gradient | >= 0.3/run | Improving, continue |
| | 0.1-0.3/run | Slow improvement |
| | < 0.1/run | Plateau, switch dataset |
| Run time | < 4 hours | Normal |
| | > 6 hours | Investigate |
